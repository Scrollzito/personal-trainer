# Machine media inventory

## Status

- The 65 files in `public/images/machines/` are imported assets stored locally in this repository. Commit `b4bd07b` describes them as "Matrix Fitness product" images; that commit message is the only provenance record currently available. Exact source URLs, creators, license terms, and permission records are not available in the project or independently verified.
- Usage permission for those imported images is therefore **unverified**. Before public or commercial distribution, replace each image with an owned or appropriately licensed asset, or record its source, license, attribution requirements, and permission evidence here.
- `public/images/machine-placeholder.svg` is a simple placeholder created locally for this project.
- The imported files contain PNG data. Their extensions were corrected from `.jpg` to `.png`; the image payloads were not altered.
